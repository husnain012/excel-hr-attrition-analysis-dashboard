# HR Attrition Analysis Dashboard (Excel)

## Project Overview
This project presents an interactive HR Attrition Analysis Dashboard built in Microsoft Excel.  
The objective is to analyze employee attrition patterns and identify key drivers impacting workforce retention using structured data modeling and visualization techniques.

## Dashboard Objectives
- Measure overall attrition rate
- Identify high-risk employee segments
- Analyze attrition by demographic and job-related factors
- Enable data-driven HR decision-making

## Key Metrics (KPIs)
- Total Employees
- Total Attrition
- Attrition Rate (%)
- Average Monthly Income
- Average Tenure

## Analysis Dimensions
The dashboard provides attrition insights across:

- Overtime Status
- Income Band
- Age Group
- Experience Category
- Job Satisfaction Level
- Department

Dynamic highlight logic is implemented to automatically emphasize the highest attrition segment within each category.

## Tools & Techniques Used
- Microsoft Excel
- Pivot Tables
- Calculated Fields
- GETPIVOTDATA
- Helper Table for dynamic highlighting
- Data aggregation and modeling
- Dashboard UI structuring and layout design

## Key Insights
- Higher attrition observed among employees working overtime.
- Young employees (18–25 age group) show elevated attrition rates.
- Sales department demonstrates the highest departmental attrition.
- Lower income bands are more prone to employee turnover.

## Business Value
This dashboard helps HR teams:
- Identify attrition drivers
- Monitor workforce risk segments
- Support strategic retention planning
- Improve workforce stability through data-driven decisions
